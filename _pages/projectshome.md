# My Projects

[Kanvas](https://github.com/kccaterworld/kanvas): An alpha-stage creative coding toolkit for Java that combines a CLI, project templates, and a .kvs sketch preprocessor to streamline visual app development. It includes config-driven builds (kanvas.toml), run/build commands, and an AWT-based rendering runtime, with plans for stronger dependency management and packaging support.

[Krusty Tools](https://github.com/kccaterworld/krusty_tools): A collection of tools written in Rust. Includes an Apache style HTTP server, very rudimentary build tools, and a project initialization tool.

[Kocoder](https://github.com/kccaterworld/kocoder): A DAW using machine learning and computer vision to apply and control audio effects and synthesizers in real-time.

[Encryption](https://github.com/kccaterworld/encryption): A repository with tools for encryption, hashing, and various ciphers.
